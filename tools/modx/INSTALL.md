# Перенос сайта Fastcup на MODX 3 (Beget)

Установщик `fc-install.php` сам делает всё внутри MODX: ставит дополнения, копирует файлы сайта, создаёт шаблоны, поля, страницы, настройки и форму заявок. Вам нужно только поставить сам MODX и один раз открыть установщик.

Что получится в админке:
- **Ресурсы → «Меню (напитки)»** — каждый напиток отдельная страница с полями: описание, картинка, слои стаканчика;
- **Ресурсы → «Точки (автоматы на карте)»** — адрес, часы работы, координаты; карта на сайте и в приложении обновляются сами;
- **«Конфигурация»** (ClientConfig) — телефон, почта, MAX, Telegram, цены 200 и 300 мл;
- **Приложения → FormIt** — все заявки с сайта (и письмо на почту из настроек);
- **Главная → вкладка полей** — «Частые вопросы»: строка `Вопрос | Ответ`.

---

## Шаг 1. Хостинг (панель Beget)

1. **Сайты** → у вашего домена выберите PHP **8.2** или **8.3**.
2. **SSL-сертификаты** → бесплатный Let's Encrypt для домена: сайт должен открываться по `https://`.

## Шаг 2. MODX 3

Вариант А (проще): **CMS → Установка CMS → MODX Revolution 3.x** на ваш домен. Запишите логин и пароль администратора.

Вариант Б (вручную):
1. **MySQL** → создайте базу, запишите имя, пользователя и пароль.
2. Скачайте MODX 3 (Traditional) с [modx.com/download](https://modx.com/download), распакуйте в корень сайта (`public_html`): там должны оказаться `index.php`, `config.core.php`, папки `core/`, `manager/`, `setup/`.
3. Откройте `https://ваш-домен/setup/` → «Новая установка» → данные базы → логин и пароль администратора → в конце отметьте «Удалить папку setup».

## Шаг 3. Архив сайта

1. **Файловый менеджер** Beget → корень сайта (`public_html`, рядом с `index.php` MODX).
2. Загрузите `fastcup-modx.zip` и распакуйте его там же (правый клик → «Распаковать»). Появится папка `fastcup-modx`.

## Шаг 4. Установщик

1. Войдите в админку: `https://ваш-домен/manager/`.
2. В той же вкладке браузера откройте `https://ваш-домен/fastcup-modx/fc-install.php?dry=1` — это **проверка**, ничего не меняется. Ошибок (красных строк) быть не должно.
3. Нажмите **«Установить»**. Займёт 1–3 минуты: скачиваются дополнения pdoTools, FormIt, ClientConfig, SendIt.
4. В конце нажмите **«Удалить папку установщика»** — она больше не нужна.

Готово: откройте сайт.

## Шаг 5. Что заполнить после установки

- **Точки**: Ресурсы → «Точки (автоматы на карте)» — сейчас там **примеры** адресов. Откройте каждую, впишите адрес, часы и координаты (в Яндекс Картах: правый клик по месту → «Что здесь?» → скопировать числа). Лишние — удалите, новые — правый клик по разделу → «Создать документ».
- **Политика конфиденциальности**: Ресурсы → «Политика конфиденциальности» — впишите реквизиты в [квадратных скобках].
- **Telegram**: «Конфигурация» → «Контакты» → ссылка на Telegram (сейчас временная).

## Как работать с сайтом

**Добавить напиток.** Ресурсы → правый клик по «Меню (напитки)» → «Создать документ». Заголовок — название напитка. На вкладке с полями: описание, картинка (необязательно — готовые стаканчики всех напитков лежат в `images/export/svg` и `images/export/png`, можно загрузить свою) или слои стаканчика. Сохранить. Порядок в меню — перетаскиванием в дереве.

**Поменять цены или контакты.** «Конфигурация» (ClientConfig). Сменили почту — запустите установщик ещё раз, чтобы заявки пошли на новую.

**Акции и «Открыто / Закрыто» в приложении** (по умолчанию выключены). «Конфигурация» → «Приложение» → поставить галочку. Акцию впишите в точку: поле «Акция в этой точке»; если в точке цены другие — «Цена 200 мл здесь» и «Цена 300 мл здесь». В приложении появятся значок «%» на метке, акция и цена в карточке, фильтры «Только с акциями» и «Сначала дешевле». «Открыто / Закрыто» считается по часам работы точки («Круглосуточно» или «07:00–23:00»).

**Убрать напиток или точку на время.** Снимите галочку «Опубликован».

**Тексты блоков** (заголовки, «О нас», «Бизнесу») — Элементы → Чанки → категория «Fastcup / Главная страница».

## Обновить сайт позже

На компьютере: `python tools/modx_build.py` → новый `dist/fastcup-modx.zip`. Загрузите и распакуйте его, как в шаге 3, откройте установщик (шаг 4). Он обновит только изменённое, а ваши правки страниц (точки, напитки, тексты главной) не тронет. Перезаписать и их: `fc-install.php?update=1` (старые версии сохранятся в `core/cache/fc-install-backup/`).

## Если что-то пошло не так

- **«Нужен вход в админку»** — войдите в `/manager/` в этом же браузере и обновите страницу установщика.
- **Ошибка дополнения** (нет связи с modx.com или modstore.pro) — поставьте его вручную: «Пакеты → Установщик» (для SendIt — добавьте поставщика `modstore.pro`, адрес `https://modstore.pro/extras/`), затем запустите установщик снова.
- **Письма не приходят** — проверьте «Приложения → FormIt»: заявки сохраняются там всегда. Отправитель писем — `noreply@ваш-домен`; другой адрес — системная настройка `fc_email_from`.
- **Журнал установки** — `core/cache/logs/fc-install-<дата>.log`.

Из консоли SSH (если удобнее): `php fastcup-modx/fc-install.php --dry`, затем без `--dry`. Ключи — в начале файла `fc-install.inc.php`.
