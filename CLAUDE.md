Инструкции для Claude Code. Читай этот файл перед любой задачей.

## О проекте
Статический одностраничный сайт: HTML + CSS + JS, без сборки, без npm, без фреймворков. Не добавляй сборщики и библиотеки без явной просьбы.

## Приложение (app/)
- Общие с сайтом файлы (points.js, map-data.js, omap.js, omap.css, картинки карты) подключаются через `../`.
- Изменил файлы app/ — увеличь `VERSION` в `app/sw.js`; пересобрал граф — `DATA_VERSION`; пересобрал карту — `TILES_VERSION` (иначе телефоны не скачают заново ≈ 4 МБ картинок зря).
- `js/points.js` и `js/config.js` приложение берёт сначала из сети (до 3 секунд), без сети — сохранённые: новые точки видны с первого открытия.
- Плавность проверяй замером кадров: у владельца слабая видеокарта.
- Жесты в приложении как в картах на телефоне: один палец двигает (с инерцией), два — масштаб, двойной тап — ближе, тап двумя пальцами — дальше. На сайте один палец листает страницу.
- Акции/цены точек и «Открыто/Закрыто» — `features` в `js/config.js` (в MODX — «Конфигурация» → «Приложение»), по умолчанию выключены; поля точки `promo`, `price200`, `price300`.
- Снимки для окна установки — `app/icons/screen-*.jpg` (780×1688); переснять после замены адресов-примеров.

## Перенос на MODX 3 (modx/)
- Сайт на хостинге Beget переезжает на MODX 3. Инструкция для владельца — `tools/modx/INSTALL.md` (кладётся в архив).
- Поменял `index.html`, `js/config.js` или `js/points.js` — запусти `python tools/modx_build.py`: он пересоберёт `modx/` и `dist/fastcup-modx.zip`. Если сборщик пишет «index.html изменился» — поправь превращения в `tools/modx_build.py`.
- В MODX напитки и точки — страницы разделов «Меню» и «Точки» с полями (TV) `fc_drink_*` и `fc_point_*`; контакты и цены — ClientConfig (`fc_phone`, `fc_email`, `fc_price_200`…). `js/points.js` и `js/config.js` на сервере пересоздаёт плагин `fcStatic`.
- Установщик проверяй на локальном MODX: `C:\cloud\modx-test` (PHP 8.3, MariaDB на порту 3307, MODX 3.2.4; сервер — `php -S 127.0.0.1:8090 -t www router.php`).

## Как проверить сайт

Открыть http://localhost:8000. Геолокация работает только на localhost или https.

## Правила для кода
- Контакты и настройки — только в `js/config.js`; точки — только в `js/points.js`. Не хардкодь их в HTML/JS.
- Цвета и шрифты бери из CSS-переменных в `:root`, новые — добавляй туда же.
- Сайт должен хорошо выглядеть на телефоне (ширина от 360px) — проверяй мобильную вёрстку.
- У каждой картинки должен быть осмысленный `alt` на русском.
- Сохраняй SEO: title, description, Open Graph, JSON-LD. Меняешь цены/меню на странице — обнови их и в JSON-LD.
- Домен пока `https://example.ru` — при замене менять в `index.html`, `robots.txt`, `sitemap.xml` одновременно.
- Не выдумывай отзывы, адреса, цены и факты о компании. Если данных нет — спроси.

## Картинки
- Исходники лежат в `images/` (некоторые по 8–9 МБ) — не трогай их, работай с копиями.
- Готовые для сайта картинки клади в `images/web/`: основной формат WebP, JPG как запасной через `<picture>`.
- Ориентиры по весу: фон/баннер до 200 КБ, обычные фото до 120 КБ, иконки до 30 КБ. Ширина баннера ~1920px, карточек ~800px.
- Инструмент: ImageMagick (`magick`). Пример: `magick images/cup.jpg -resize 800x -quality 80 images/web/cup.webp`.
- После добавления картинки проверь, что путь в HTML/CSS верный.
